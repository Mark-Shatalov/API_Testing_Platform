# Geist interface fonts

Unmodified static TrueType fonts from [Vercel Geist](https://github.com/vercel/geist-font/tree/main/fonts/Geist/ttf),
downloaded on 4 November 2026. Regular, Medium and SemiBold are registered once by `MainView.stylesheet()`.
The font files are bundled in the application; no runtime network access or system font installation is required.
